# Components

This folder contains the reusable UI building blocks of WealthSmith.

Each component should be documented individually.

Examples include:

- Button
- Card
- Input
- Select
- Checkbox
- Radio Group
- Modal
- Drawer
- Sidebar
- Table
- Tabs
- Tooltip
- Toast
- Badge
- Empty State
- Suggestion Card
- Portfolio Card
- Metric Card
- Chart
- Navigation
- Pagination

Each component document should describe:

- Purpose
- When to use it
- When not to use it
- Variants
- Sizes
- States (default, hover, active, disabled, loading)
- Properties (props)
- Responsive behavior
- Accessibility requirements
- Usage examples
- Do's and Don'ts

This folder is the single source of truth for all reusable UI components used throughout WealthSmith.
