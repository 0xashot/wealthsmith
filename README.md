# WealthSmith Design System

## Purpose

The WealthSmith Design System is the single source of truth for the product's design, user experience, and interface behavior.

It exists to ensure that every screen, component, and interaction is built consistently across the WealthSmith ecosystem.

This repository is used by:

- Designers
- Product Managers
- Engineers
- AI coding assistants (Claude Code, ChatGPT, Cursor, etc.)

---

## Repository Structure

```
tokens/
```

Design tokens including colors, spacing, typography, breakpoints, shadows, radius, and other primitive values.

```
components/
```

Reusable UI components.

```
patterns/
```

Reusable screen layouts and interaction patterns.

```
content/
```

Writing guidelines and UI copy rules.

```
rules/
```

Business logic that influences UI behavior.

```
examples/
```

Reference implementations and examples.

```
assets/
```

Icons, illustrations, logos, and visual resources.

```
templates/
```

Reusable page templates.

---

## Design Principles

Everything built from this design system must follow these principles:

- Trust First
- Clarity over Cleverness
- Readability
- Consistency
- Accessibility
- Explainability
- Mobile First

---

## Source of Truth

If something is not documented here, it should not be invented.

If two sources conflict, this repository takes precedence.
