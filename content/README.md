# Content

This folder defines all writing standards used throughout WealthSmith.

Topics include:

- Voice and Tone
- Button Labels
- Empty States
- Tooltips
- Error Messages
- Success Messages
- Notifications
- AI Responses
- Suggestion Copy

The goal is to ensure every screen speaks with the same voice.

UI copy should always prioritize:

- Clarity
- Trust
- Simplicity
- Explainability
